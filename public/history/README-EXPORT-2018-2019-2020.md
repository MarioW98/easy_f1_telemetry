# Export archivi 2018, 2019, 2020 — istruzioni per il run locale

## Perché serve eseguire in locale

Dal **15 ottobre 2026** Formula 1 richiede l'autenticazione (abbonamento F1 TV)
per scaricare l'archivio telemetry da `livetiming.formula1.com` (errore 401/403
senza token — vedi [Fast-F1 issue #978](https://github.com/theOehrly/Fast-F1/issues/978)).

Il mirror pubblico di FastF1 (`livetiming-mirror.fastf1.dev`) copre **solo
2021 e 2022**: per questo gli archivi 2021-2024 sono stati esportati senza
problemi, mentre **2018, 2019 e 2020 sono scaricabili solo con un account
F1 TV (Access o superiore)**. Le credenziali restano sul tuo computer: FastF1
le invia esclusivamente ai server di Formula 1 e non le salva.

## Requisiti

- Python 3.10+
- Abbonamento **F1 TV Access** (o superiore) attivo
- Repository clonato localmente

## Procedura (3 comandi)

```bash
# 1. installare la versione di fastf1 con supporto all'autenticazione
python -m pip install "fastf1>=3.9,<4"

# 2. autenticarsi una volta (token valido ~4 giorni, poi rifare)
python -m fastf1 auth f1tv --authenticate

# 3. esportare i tre anni (riprendibile: se si interrompe, rilancia e continua)
python public/history/export_2018_2019_2020.py
```

Login non interattivo (opzionale): imposta prima le variabili d'ambiente
`F1_USERNAME` e `F1_PASSWORD`, poi lancia `--authenticate`.

## Cosa produce

```
public/data/archives/2018/   ~105 file JSON (una sessione = un file)
public/data/archives/2019/   ~110 file JSON
public/data/archives/2020/    ~85 file JSON
public/data/archives/manifest.json   (rigenerato automaticamente, tutti gli anni)
```

Formato `f1-telemetry-lab/v1`, mode `compact` (giro più veloce per pilota),
come gli archivi 2021-2024 già presenti. Totale stimato: ~250-300 MB di JSON.
Tempo stimato: 1,5-3 ore a seconda della connessione (ogni sessione scarica
gli stream completi timing/posizione/macchina prima di compattarli).

Qualche sessione può mancare (per es. qualche FP1): nell'archivio ufficiale
alcune sessioni di quelle stagioni non hanno dati. È lo stesso comportamento
visto per il 2021 (21 FP1 su 22).

## Dopo l'export

1. Verifica rapida: `ls public/data/archives/2018 | wc -l` (attesi ~105, ecc.)
2. Commit e push di `public/data/archives/`:
   il sito pubblica gli anni dal manifest, nessun'altra modifica necessaria.
3. Il workflow `update-archives.yml` **non** può esportare questi anni al posto
   tuo (i runner GitHub non hanno account F1 TV): serve il run locale.

## Nota

I termini di servizio F1 non consentono la ridistribuzione dei dati
scaricati con autenticazione (discussione Fast-F1 #978). La scelta di come
usare i dati esportati resta tua.
