- F1 Telemetry Lab fetches OpenF1 directly from the browser via src/lib/openf1.ts (cache + serialized rate-limited queue); no backend needed because OpenF1 historical data is public with CORS.
- Two data sources, switched by the SourceSwitcher (persisted in localStorage via the Zustand store): "openf1" (2023+, API) and "local" (FastF1 2018-2022 archives). Session keys are negative for archives and positive for OpenF1; react-query keys always include the source so caches never mix.
- Local archives come from the repository itself (public/data/archives/<year>/<session>.json + manifest.json, downloaded per-session by ArchiveManager — compact mode, fastest lap per driver, 1-4 MB each) or from user-imported JSON/ZIP files (ArchiveImporter + archive-import.ts). Keep repo-hosted files compact and under 95 MB: Git blocks files >100 MB and the browser JSON limit is 64 MB.
- Raw FastF1 downloads are whole-session streams (cannot be partial): only the generator workflow (.github/workflows/update-archives.yml, manual dispatch, default race+compact, optional --rounds to split a year) pays that cost on CI. Never commit raw FastF1 caches or full-season archives.
- The site is a static SPA deployed on GitHub Pages — there is no server runtime. Any absolute asset URL must use `import.meta.env.BASE_URL` as prefix, and the deploy build runs with `--base=/<repo-name>/`.
- Playback uses one shared clock (src/hooks/use-playback.ts); charts are memoized and the cursor is an overlay so 60fps updates do not re-render Recharts. The playback clock intentionally stays out of the Zustand store.
- Global state lives in src/store/appStore.ts (Zustand + persist: only `source` and `visible` are persisted; selection state resets on source switch because OpenF1 and archive keys are disjoint).
- Data access goes through src/services/dataSource.ts (DataSource interface): openf1Source.ts and localArchiveSource.ts implement it; useTelemetryData/useLapQueries bind it to react-query. Do not bypass the service layer in components.
- Match circuits by OpenF1 circuit_key, falling back to normalized circuit names for imported archives; do not artificially align coordinates across years because layouts and coordinate frames can differ. Never invent track geometry.
